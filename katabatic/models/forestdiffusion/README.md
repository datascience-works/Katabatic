# ForestDiffusion Model

## Model Overview
ForestDiffusion is a **tree-based score matching generative model** for tabular data that replaces the neural network denoiser in a standard diffusion model with gradient-boosted trees (XGBoost by default).

The model learns a **score function** across diffusion timesteps using an ensemble of regressors, then uses a **reverse SDE** (Euler-Maruyama) to generate synthetic samples from Gaussian noise.

This implementation is self-contained using XGBoost, scikit-learn, numpy, and pandas.

---

## Approach
The model follows a diffusion-based generative pipeline:

- Corrupts real training data with Gaussian noise at multiple timesteps via a **VP-SDE** (Variance Preserving SDE)
- Trains one regressor per (class label, diffusion timestep) to estimate the **denoising score** at each noise level
- Reverses the diffusion process using **Euler-Maruyama** integration of the reverse SDE to recover clean samples from noise

### Key Idea
Standard diffusion models use neural networks as the denoiser. ForestDiffusion replaces this with gradient-boosted trees, which are better suited to tabular data — they handle heterogeneous feature types natively, do not require careful hyperparameter tuning for stability, and train faster on CPU.

---

## Diffusion Process
Uses a **Variance Preserving SDE (VP-SDE)**:

```math
dx = -\frac{1}{2}\beta(t)x\,dt + \sqrt{\beta(t)}\,dW
```

where β(t) increases linearly from `beta_min` to `beta_max`.

### Score Matching Objective
Each regressor is trained to predict the **denoising score target**:

```math
s_\theta(x_t, t) \approx -\frac{\epsilon}{\sigma_t}
```

where ε is the added noise and σ_t is the marginal standard deviation at time t.

### Reverse SDE (Euler-Maruyama)
Samples are generated by integrating backwards from t=T to t=ε:

```math
x_{t-h} = x_t - h \cdot \text{drift}(x_t, t) + \sqrt{h} \cdot \text{diffusion}(t) \cdot z
```

## Supported Backends
The model supports multiple regressor backends:

- **XGBoost** (default)
- **Random Forest** (`model="random_forest"`)
- **LightGBM** (`model="lgbm"`) — requires optional install
- **CatBoost** (`model="catboost"`) — requires optional install

---

## Hyperparameters
Defined in `ForestDiffusionModel`:

- `n_t = 50`
- `model = "xgboost"`
- `max_depth = 7`
- `n_estimators = 100`
- `eta = 0.3`
- `beta_min = 0.1`
- `beta_max = 8.0`
- `eps = 1e-3`
- `subsample = 1.0`
- `reg_alpha = 0.0`
- `reg_lambda = 0.0`
- `seed = 666`

---

## Input
- `X`: Tabular feature matrix
- `y`: Target labels

### Expected Files
- `x_train.csv`
- `y_train.csv`

---

## Preprocessing
The model automatically handles mixed tabular data types:

### Categorical Features
- Ordinal-encoded using `sklearn.preprocessing.OrdinalEncoder` when object columns are detected

### Numerical Features
- Scaled to [−1, 1] using `sklearn.preprocessing.MinMaxScaler`

### During Generation
- Inverse scaling applied to recover original value ranges
- Integer columns rounded via `int_indexes` parameter
- Values clipped to training data min/max per column

---

## Label Handling
Labels are **not** passed through the diffusion process. Instead:
- Class distribution is estimated from training labels
- Synthetic labels are sampled empirically from the training label distribution

This guarantees all classes appear in correct proportions regardless of rarity.

---

## Output
Generated files:

- `x_synth.csv`
- `y_synth.csv`

---

## Evaluation
`evaluate()` returns the **mean column-wise KS statistic** between real and synthetic numeric features. Lower is better; 0 indicates identical marginal distributions.

---

## Strengths
- Tree-based denoiser is well-suited to tabular data heterogeneity
- No GPU required for good performance
- Class-conditional generation via label-stratified score functions
- Supports multiple gradient boosting backends

---

## Limitations
⚠️ The model may struggle with:
- Very high-dimensional datasets (one regressor per timestep × class × column)
- Large numbers of distinct class labels (memory scales with n_classes × n_t)
- Purely categorical datasets without numerical features

⚠️ Training time scales with `n_t × n_classes × n_estimators`.

---

## Usage

```python
from models import ForestDiffusionModel

model = ForestDiffusionModel(n_t=50, model="xgboost")

model.train(
    output_dir="path_to_data",
    synthetic_dir="path_to_save"
)

X_synth, y_synth = model.sample(1000)
```
