# TabEBM Model

## Model Overview
TabEBM (Tabular Energy-Based Model) is a generative model for tabular data that leverages **energy-based learning** and **Stochastic Gradient Langevin Dynamics (SGLD)** to generate synthetic samples.

Instead of explicitly modeling a probability distribution, TabEBM learns an **energy landscape**, where realistic data points lie in low-energy regions. Synthetic samples are generated by iteratively moving points toward these low-energy regions.

---

## Approach
The model follows an energy-based sampling process:

- Encodes tabular data into a numeric format:
  - Continuous → z-score normalization  
  - Categorical → ordinal encoding  
- Introduces **surrogate negative samples** to shape the energy function  
- Uses **SGLD (Stochastic Gradient Langevin Dynamics)** to iteratively refine samples  
- Generates synthetic data class-by-class to preserve label distribution  

**Key idea:**
- Real data → low energy  
- Synthetic data → optimized via gradient descent + noise injection  

---

## Training Details
- No traditional neural network training loop  
- Schema inference + encoding performed on input data  
- Sampling-driven generation using:
  - Gradient-based updates  
  - Noise injection per step  
- Default SGLD steps: **200**

---

## Hyperparameters
Defined in `TabEBMConfig`:

- `max_data_size = 10000`  
  Limits dataset size for scalability  

- `starting_point_noise_std = 0.01`  
  Initial noise added to starting samples  

- `sgld_step_size = 0.01`  
  Step size for gradient updates  

- `sgld_noise_std = 0.01`  
  Noise injected at each SGLD step  

- `sgld_steps = 200`  
  Number of SGLD iterations  

- `distance_negative_class = 5.0`  
  Distance used to generate surrogate negative samples  

- `seed = 42`  
  Random seed for reproducibility  

---

## Input
- `X`: Tabular dataset (CSV loaded internally)  
- `y`: Target labels (separate CSV)  

**Expected structure:**
- `x_train.csv`  
- `y_train.csv`  

---

## Output
- `x_synth.csv`: Synthetic features  
- `y_synth.csv`: Synthetic labels  

Generated samples preserve:
- Feature structure  
- Class distribution
