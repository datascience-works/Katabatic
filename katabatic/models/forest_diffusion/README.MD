# Forest Diffusion

**Forest Diffusion** is a tree-based diffusion / flow-matching framework for tabular data synthesis. It replaces neural networks with ensemble tree regressors to learn a denoising vector field that transforms noise into realistic tabular samples. This implementation serves as a **non-private, non-neural diffusion baseline** for Katabatic TSTR pipelines, with **intentional adaptations** to support tractable experimentation and cross-model comparison.

***

## Overview

This implementation follows the core idea of Forest Diffusion, **adapted specifically for tabular data generation**:

- **Diffusion-style generation**: Samples are generated by progressively transforming noise into data
- **Flow matching**: A time-dependent vector field is learned to map noisy samples toward real data
- **Tree-based modeling**: Decision tree ensembles replace neural networks for stability and interpretability

This approach is well-suited for **structured tabular datasets with mixed feature types**, avoiding many of the convergence issues seen in neural diffusion models.

***

## Key Features

This Katabatic adaptation provides:
- Diffusion / flow-matching generation without neural networks
- Tree-based regressors optimized for tabular data
- Explicit time conditioning for vector-field learning
- Stable and CPU-friendly training
- Compatibility with continuous, categorical, integer, and binary features
- Seamless integration with Katabatic’s Train–Test–Split and TSTR evaluation pipeline

***

## Implementation Details

**Paper**: Jolicoeur-Martineau, A. et al. (2024). *Generating and Imputing Tabular Data via Diffusion and Flow-based Gradient-Boosted Trees*. https://arxiv.org/pdf/2309.09968
**Repository**: Samsung SAIL Forest Diffusion (reference implementation)

### Paper Training Recipe

- Noise–data interpolation:

  x_t = (1 − t) · x_0 + t · x_1

- Learning a time-dependent vector field:

  v(x_t, t) ≈ x_1 − x_0

- One or more tree ensembles trained to approximate the vector field
- ODE-based sampling to transform noise into data

### Katabatic Implementation

**Vector Field Model**:

Input: (x_t, t)
Output: direction vector v

- Single multi-output tree-based regressor
- Time variable t explicitly included as an input feature
- Supports Random Forest, Gradient Boosting, or histogram-based GBRT backends

**Sampling Strategy**:

- Initialize samples from Gaussian noise
- Euler integration from t = 0 → 1
- Post-processing to restore valid tabular structure

**Data Processing (tabular-specific)**:
- Optional one-hot encoding for categorical features
- Min–max normalization to [−1, 1]
- Integer and binary column rounding
- Value clipping using training-set bounds

## Hyperparameter Comparison

| Aspect | Original Paper | **Katabatic** | **Rationale** |
|------|---------------|---------------|---------------|
| Time models | Multiple / per-step | **Single shared model** | Reduce training cost |
| Training data | Full duplication | **Random pair sampling** | Scalable training |
| Time conditioning | Implicit | **Explicit feature** | Parameter sharing |
| Training budget | Research-scale | **Capped** | Practical runtime |
| Evaluation | Likelihood / quality | **Utility (TSTR)** | Cross-model fairness |

**These adaptations preserve the diffusion formulation while enabling tractable experimentation.**

***

## Original vs Katabatic Implementation

**Reference implementation**:
- Research-oriented diffusion framework
- Heavy training loops and dataset-specific configurations
- Standalone execution and evaluation scripts
- Emphasis on likelihood-based modeling

**Katabatic adaptation**:
- Single time-conditioned vector-field model
- Randomized noisy-pair construction instead of full dataset duplication
- Unified preprocessing and evaluation across models
- Integrated into Katabatic `TrainTestSplitPipeline`
- Optimized for repeated multi-dataset benchmarking

***

## Deviations from Original Paper

This implementation preserves the **core Forest Diffusion concept** while introducing **intentional, experiment-driven adaptations**:

1. Single shared vector-field regressor instead of multiple time-specific models
2. Explicit time conditioning to enable parameter sharing
3. Randomized noisy-pair sampling for scalable training
4. Fixed training budgets across datasets
5. Utility-only evaluation using TSTR
6. Pipeline-based execution replacing standalone scripts

**These deviations ensure computational feasibility, methodological consistency, and fair comparison across heterogeneous generative models.**
