# PrivTree

PrivTree is a tree-based synthetic data generation approach that uses noisy counts during recursive partitioning of tabular data.

For synthetic tabular data generation, the model recursively divides the training data into tree nodes, stores distributions at the leaf nodes, and samples new synthetic records from the learned leaf-level distributions.

This Katabatic implementation is adapted from the **PrivTree implementation contributed by Rishi Goyal** to the Katabatic mentorship repository.

---

## Overview

This implementation integrates the following core ideas, **adapted specifically for Katabatic**:

- **Tree-based partitioning**: The training data is recursively divided into left and right child nodes.
- **Differentially private counts**: Laplace noise is added to node counts using the configured privacy parameter `epsilon`.
- **Balanced split selection**: Candidate feature splits are evaluated using noisy counts, with preference given to more balanced partitions.
- **Leaf distributions**: When a node is no longer split, per-column value distributions are stored for synthetic sampling.
- **Synthetic row generation**: New rows are generated by traversing the trained tree and sampling values from the selected leaf distributions.
- **Reproducible sampling**: A random seed can be provided during synthetic data generation to support Katabatic stability evaluation.

```text
    Add Laplace noise to the node count
    Check maximum depth and minimum count
    Select a valid feature split

    Calculate noisy child counts
    Recursively build child nodes

At each leaf:
    Store per-column value distributions

```

### Training Process

```text
1. Store the input dataframe column names.
2. Calculate the root record count.
3. Apply Laplace noise to the root count.
4. Create the root tree node.
5. Recursively determine whether each node should be split.
6. Evaluate candidate feature splits using noisy left and right counts.
7. Create child nodes and recursively continue tree construction.
8. Store per-column value distributions when a leaf node is reached.
```

### Synthetic Data Generation

```text
1. Start at the root node.
2. Traverse the tree until a leaf node is reached.
3. Select the left or right child during traversal.
4. At the leaf, retrieve the stored distribution for each column.
5. Sample one value for every column using its learned probability distribution.
6. Repeat until the requested number of synthetic rows has been generated.
7. Return the synthetic records as a pandas DataFrame.
```

For compatibility with the Katabatic evaluation pipeline, the model also provides:

```python
sample(n_rows, seed=None)
```

This allows reproducible sampling during stability evaluation while preserving the original `generate()` method.

## Data Processing

The PrivTree implementation operates on categorical or discrete feature values and uses the dataframe produced by the Katabatic preprocessing pipeline.

### Categorical Features

- Unique values are treated as possible categories during split selection.
- Candidate values are divided into left and right groups.
- Leaf-level value distributions are used during synthetic sampling.
- Generated categorical values are handled through Katabatic's existing synthetic-data saving workflow.

### Continuous Features

- Continuous values supplied by the Katabatic preprocessing pipeline are processed using the same tree-based split logic.
- Unique feature values can be used when selecting candidate tree partitions.
- Generated continuous values are passed through Katabatic's existing synthetic-data saving and evaluation workflow.

### Target Column

- The target column is included in the dataframe used to train the tree.
- Its distribution is learned together with the remaining columns.
- Synthetic target values are sampled from the learned leaf-level distributions.

## Differential Privacy Mechanism

The implementation uses the Laplace mechanism to add noise to record counts.

```text
noisy_count =
    true_count + Laplace(0, sensitivity / epsilon)
```

The default count sensitivity is:

```text
1.0
```

The model divides the configured privacy parameter across tree levels using:

```text
epsilon_per_level = epsilon / max_depth
```

The implementation follows the structure of the source contribution and is described as a **PrivTree-style implementation** rather than an exact reproduction of every privacy-accounting detail of the original PrivTree research algorithm.
