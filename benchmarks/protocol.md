# Benchmark protocol

Status: DRAFT v3 (rolled out to the scripts), written by the Benchmarking & Evaluation stream. Items marked
"to confirm" need approval from the stream lead before any script is changed.

The goal is that every model is trained and scored under the same conditions so
results can be compared fairly. The rules are stored in `benchmarks/protocol.py`
and checked automatically by `benchmarks/check_protocol.py`.

## 1. Data and split

| Setting | Value | Where it is set |
| --- | --- | --- |
| Datasets | adult, shuttle, car, magic, nursery | `katabatic/datasets/` |
| Test share | 20% (`TEST_SIZE = 0.2`) | `RunConfig` in `benchmarks/runner.py` |
| Split seed | 42 (`SEED = 42`) | `RunConfig` in `benchmarks/runner.py` |
| Training row cap | 50,000 (`MAX_TRAIN_ROWS`) | `RunConfig` in `benchmarks/runner.py` |

## 2. Random seed

Every model that accepts a seed uses 42, passed explicitly in the script. Do not
rely on a model default, because defaults differ (RealTabFormer defaults to
1029, TabKDE to no seed). A model with no seed argument is marked REVIEW until
someone checks its code.

## 3. Dataset size groups (to confirm)

| Group | Rule | Datasets (rows) |
| --- | --- | --- |
| Small | under 5,000 rows | car (1,728) |
| Medium | 5,000 to 25,000 rows | nursery (12,960), magic (19,020) |
| Large | over 25,000 rows | adult (32,561), shuttle (58,000) |

## 4. Training budget policies

Each model has one of three policies in `MODEL_SPECS`:

| Policy | Rule | Models |
| --- | --- | --- |
| standard | Epochs equal 100 for small and medium datasets and 150 for large ones (to confirm) | codi, ctgan, fairtabdiffusion, ganblr, tvaegan |
| specific | The model keeps its own budget, documented with a reason (iterations, steps, two-stage training) | great, medgan, pategan, realtabformer, tabddpm, tabebm, tabsyn |
| fixed | No training loop; default settings are kept | arf, gmm, histogram, kde, mst, naivebayes, privtree, smote, synthpop, tabkde |

Equal epochs are not always equal effort. Models with a different budget unit
(steps, iterations) are therefore kept on their own settings, and the runtime
report (deliverable 6) records the real time spent so the comparison stays
honest.

## 5. Scoring

All models are reported with the same six measures (fidelity, utility,
diversity, privacy, consistency, stability) and the default composite weights.
Two results are only compared directly if they were scored on the same set of
dimensions (see deliverable 9).

## 7. Rollout result (18 Nov 2026)

The first check found 28 problems in 110 scripts. They were fixed in one change:

- **Seeds.** Every script whose model accepts a seed now sets 42, through `SEED`
  imported from `benchmarks/protocol.py` (TabDDPM relies on its own default of 42). TabKDE and TabSyn now pass their seed, and
  RealTabFormer uses 42 instead of its default 1029. GANBLR and GReaT accept a
  seed for sampling only. MST has no seed argument, so it is marked N/A.
- **Epochs.** CoDi, CTGAN, FairTabDiffusion, GANBLR and TVAE-GAN now take their
  epochs from `epochs_for(dataset)`. This changes training time and results for
  those five models, so earlier runs of them are not comparable.
- **Models on their own budget** (GReaT, MedGAN, PATE-GAN, RealTabFormer,
  TabDDPM, TabEBM, TabSyn) are unchanged. See section 4.

`python benchmarks/check_protocol.py` now reports 0 DIFF or MISSING findings,
and a test (`test_all_scripts_follow_the_protocol`) keeps it that way.

## 8. How to check

```
python benchmarks/check_protocol.py              # summary per model
python benchmarks/check_protocol.py --verbose    # one line per script
python benchmarks/check_protocol.py --strict     # exit code 1 on any DIFF/MISSING
```

The checker only reads the scripts. It never trains a model.

## 9. Rollout plan

1. The lead confirms sections 3 and 4.
2. If a decision changes a rule, edit `benchmarks/protocol.py` (for example
   `EPOCHS_BY_SIZE`). The scripts follow it automatically for the five standard
   models, and the checker and test confirm it.
3. A new or changed script must pass `python benchmarks/check_protocol.py`.
4. Models that pass are ready for the full run (deliverable 11).
